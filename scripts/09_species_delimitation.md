### Species Delimitation Methods

We used the following species delimitation methods:
- **bPTP**: Bayesian Poisson Tree Process (https://species.h-its.org/ptp/)
- **ABGD**: Automatic Barcode Gap Discovery (https://bioinfo.mnhn.fr/abi/public/abgd/)
- **ASAP**: https://bioinfo.mnhn.fr/abi/public/asap/
- **GMYC**: General Mixed Yule-Coalescent Model
- **LIMES**: to compare partitions

All were run with default parameters and results compared for consistency.
